# GUIDEPOST.md

Permission-guarded project scope charter for `bulletin-tools`.

Do not edit this file without explicit user approval. If work implies a change to outcome, users, scope boundaries, non-goals, non-negotiables, or locked decisions, stop and ask first.

## Project North Star

`bulletin-tools` makes ambiguous OpenClaw agent decisions auditable through structured bulletin discussion, critique, and resolution instead of unilateral guessing.

Primary users are OpenClaw operators and subscribed OpenClaw agents coordinating asynchronous decisions.

Primary value is documented multi-agent reasoning with clear positions, reservations, dissent escalation, critique rounds, and closure summaries.

Done means an operator can configure subscriber groups and channels, agents can create/respond to bulletins, the system can wake subscribers, decision rounds resolve according to protocol, and the outcome leaves durable state and an audit trail.

## Scope Boundaries

### In Scope

- OpenClaw plugin registration and lifecycle hooks.
- MCP tools for listing, responding to, and critiquing bulletins.
- Bulletin protocols: `advisory`, `consensus`, `majority`, and `fyi`.
- Ternary positions: `align`, `partial`, and `oppose`.
- Subscriber group expansion from `~/.openclaw/mailroom/agent-groups.json`.
- Discord thread notifications, escalation alerts, and closure summaries.
- SQLite persistence, FTS search, read cursors, critique cursors, and audit logging.
- Agent wake behavior for pending bulletins.
- ClawHub-public plugin packaging and docs.

### Out Of Scope

- Using GitHub's issue tracker as the canonical tracker.
- Claiming non-Discord platform support as tested before live verification.
- Plugin-level private ACLs beyond subscriber routing and platform channel permissions.
- Replacing Linear with repository markdown as the canonical work tracker.
- Quietly changing the response model, protocol semantics, or persistence contract.

### Deferred / Parking Lot

- Channel-agnostic notification support through a future OpenClaw message abstraction.
- Clarifying whether the long-term wake architecture is `subagent.run()` plus HTTP fallback or the March CronService/lightContext design.
- Clarifying whether JSON backup bulletin files remain a supported persistence surface or SQLite is the only intended runtime source.
- Resolving audit-log path naming between `audit.log`, `bulletins.log`, and CLI logs.

## Non-Negotiables

- Preserve the ternary response model. `partial` must include reservations.
- Preserve critique-round semantics for protocols that require them.
- Keep FTS updates synchronized with source table mutations in the same transaction.
- Keep round transitions and bulletin closes race-safe with atomic SQL updates.
- Keep Discord-only support explicit until another platform is implemented and tested.
- Keep channel-level permissions as the stated privacy boundary.
- Verify runtime-sensitive claims before reporting them as done.
